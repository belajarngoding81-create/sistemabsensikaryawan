# UI/UX Design Guide HRIS Absensi Karyawan

## 1. Tujuan Desain
Antarmuka dirancang agar cepat dipakai, jelas secara visual, dan nyaman diakses dari desktop maupun perangkat mobile. Fokus utamanya adalah kenyamanan pengguna saat absensi dan pengajuan ketidakhadiran.

## 2. Tema Visual
- Nama tema: Soft Amber Executive
- Nuansa: clean light mode, card floating, shadow lembut, aksen orange-amber
- Kesan: profesional, modern, dan mudah dibaca

## 3. Palet Warna
- Background canvas: #F8F9FA
- Surface card: #FFFFFF
- Primary accent: orange ke amber gradient
- Heading: #344767
- Body text: #67748E
- Success: emerald green
- Warning/error: rose red

## 4. Tipografi
- Gunakan font yang bersih dan modern seperti Inter, Poppins, atau Manrope.
- Heading tegas dan ringkas.
- Body text cukup lega agar nyaman dibaca di layar kecil.

## 5. Prinsip UX
- Satu aksi utama di layar utama untuk absensi cepat.
- Hindari terlalu banyak langkah untuk tugas rutin.
- Tampilkan informasi penting di atas layar untuk mengurangi scrolling.
- Berikan feedback visual saat aksi sukses atau gagal.

## 6. Komponen UI yang Disarankan
- Sidebar navigasi untuk desktop
- Topbar untuk pencarian, notifikasi, dan profil
- Kartu statistik dengan ikon gradient
- Tabel data dengan status badge
- Modal / drawer untuk detail dan form pengajuan
- Bottom navigation untuk mobile

## 7. UX untuk Mobile PWA
- Tampilan utama menonjolkan tombol absensi.
- Indikator koneksi Wi-Fi kantor harus jelas terlihat.
- Form pengajuan harus sederhana dan tidak memakan banyak ruang.
- Prioritaskan aksi yang sering dipakai seperti clock-in, approval, dan dashboard.

## 8. Aksesibilitas
- Kontras warna cukup tinggi.
- Tombol dan input memiliki ukuran yang cukup nyaman.
- Navigasi harus tetap jelas untuk keyboard dan screen reader.
- Hindari elemen yang terlalu padat.
